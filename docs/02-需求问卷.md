## 第四类："免 token"的真正含义（决定架构底线）

**Q7. "免 token"对你的核心含义是？（可多选）**

- [ ] A. 用户拿到就能用，不需要注册账号、不需要申请 API Key —— **零门槛**

- [ ] D. 即使目标 API 挂了，插件也要能用（要有兜底）
