**设计原则：数据源抽象 + 缓存优先 + 限流降级。** 插件主体只依赖 `DataSource` 接口，主源挂了自动切兜底源，用户无感。

## §2 技术选型

| 层 | 选型 | 理由 |
| --- | --- | --- |
| 扩展框架 | Manifest V3 + TypeScript | Chrome/Edge 现行标准；TS 减少类型错误 |
| UI | 原生 Web Components 或 Preact | 扩展弹窗小、无重依赖；避免 React 体积 |
| 本地缓存 | chrome.storage.local（JSON）+ 内存 LRU | 零依赖；KV 结构适配诗词条目 |
| 离线包 | 静态 JSON 分片（按朝代/体裁分文件，lazy 加载） | 可增量下载，不必一次装 50MB |
| 构建 | Vite + @crxjs/vite-plugin | 热更新 + 自动生成 manifest |
| 测试 | Vitest（核心逻辑）+ Playwright（扩展 e2e） | 限流调度器必须有单测 |

## §3 核心模块设计

### 3.1 数据源抽象（应对"免 token + 有兜底"）

```ts
interface DataSource {
  id: string;                    // 'public' | 'offline' | 'selfhost'
  health(): Promise<boolean>;
  randomPoem(filters?): Promise<Poem>;
  search(query, page?): Promise<Poem[]>;
  authors/dynasties/types(): Promise<Meta[]>;
}

// 优先级链：public → offline → selfhost（配置中可自定义顺序）
class DataSourceRouter {
  async fetch<T>(op: () => Promise<T>, params): Promise<T> {
    for (const src of this.priorityChain) {
      if (await src.health()) {
        try { return await op(); } catch { continue; /* 降级 */ }
      }
    }
    throw new PoetryError('所有数据源不可用');
  }
}
```

### 3.2 请求调度器（消化限流，本方案关键技术点）

- **令牌桶限速**：普通接口 20 次/分钟、搜索 8 次/分钟，客户端自设安全系数（如 15/6），留余量给其他进程。
- **缓存优先**：搜索结果、诗词详情、元数据列表全部缓存到 `chrome.storage.local`，TTL 策略：
  - 元数据（朝代/体裁/作者）：7 天
  - 搜索结果：24 小时
  - 随机诗词：不缓存（保持新鲜），但受限速保护
- **429 处理**：读 `Retry-After` 头 → 指数退避（1s/2s/4s…上限 60s）→ 若连续 3 次 429 自动切离线源。
- **队列**：并发 1，FIFO + 优先级（搜索 > 随机 > 元数据）。

```
预期效果：常规使用（<15 次/分钟）永远不会触发 429；高频场景自动降级离线，体验不断档。
```

### 3.3 功能清单（🔧 按问卷 Q5 调整优先级）

| 优先级 | 功能 | 实现要点 |
| --- | --- | --- |
| P0 | 搜索（全文/标题/作者） | `/api/search?q=`，≥2 字校验，结果高亮 |
| P0 | 随机诗词 | `/api/poems/random`，支持作者/体裁/单字过滤 |
| P0 | 详情展示 | 标题/作者/朝代/体裁/正文分行，简繁切换 |
| P1 | 右键查诗 | contextMenus：选中文本→查诗句/查作者 |
| P1 | 收藏 + 历史 | chrome.storage.local 纯本地，导出 JSON |
| P1 | 飞花令 | `random?char=` + 本地索引增强 |
| P2 | 每日一首 | 开机/定时通知 + 快捷卡片 |
| P2 | 分享卡片 | Canvas 生成宣纸风格图片（古风字体可选内置） |
| P3 | 离线包 | 设置页按需下载分片（唐诗→宋词→元曲…） |
| P3 | 自建实例接入 | 设置页填 URL，自动测试连通性 |

### 3.4 隐私设计（达成"数据本地化"）

- 所有用户数据（收藏、历史、设置）**仅存本地** `chrome.storage`，零云同步。
- 对外请求仅发往数据源 API，且**不含任何用户身份信息**（公共 API 本身也不收集）。
- 扩展权限最小化：仅 `storage` + `contextMenus` + `alarms`，无 `host_permissions` 通配（仅在用户点选时按需请求）。

## §5 风险与对策（承接调查报告 §3.7）

| 风险 | 对策 | 成本 |
| --- | --- | --- |
| 限流 | 调度器 + 缓存 + 降级 | 已在 §3.2 设计，约 1 天开发 |
| 主源停服 | 优先级链自动切换 → 离线包保底 | 离线包是主要工作量（P3） |
| 接口变更 | 端点集中在 config，一键改 | 低 |
| 单字搜索 400 | UI 层输入校验 + 本地提示 | 低 |
| GPL 误用 | 插件本体不复制其代码，仅 HTTP 调用；自建实例另开源 | 零 |
