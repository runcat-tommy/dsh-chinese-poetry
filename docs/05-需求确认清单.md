## 三、「免 token」边界（关键决策）

| 项 | 你的选择 | 方案落点 |
| --- | --- | --- |
| 免 token 含义 | A 零门槛 + B 不依赖付费/实名第三方 | 查询功能全部走**免费公共 API**，无注册无 Key |
| 生成式功能 | 允许用 dsh 大模型（**接受 token**） | AI 解读/典故/节日推荐走 **dsh 自己的会话**（`inputActions` 提交给当前 agent），token 即用户已有的 dsh 配额 |
| 兜底 | D 纯本地/纯公共 API（**不建后端**） | 不做自建 Docker 服务；以「本地缓存 + 限速 + 可选离线小数据包」保底 |

> 说明：公共 API 有 20 次/分（普通）/8 次/分（搜索）的 IP 限流。方案通过**客户端缓存 + 令牌桶限速 + 429 退避**消化，保证日常使用（<15 次/分）不触发 429，且绝无"用几次就报错"。

## 五、与你最初设想的差异（重要）

你最初设想是"浏览器扩展/命令行"等形态，问卷回答后改为 **DSH Web 插件**。这意味着：

1. **无需安装扩展**：`dsh plugin --profile web add dsh-chinese-poetry` 一行命令 + 重启即用（或发布到 npm 后 `dsh plugin add`）。
2. **与 AI 天然集成**：AI 解读直接复用你正在用的 dsh 会话，**不需要额外申请任何模型 API Key**。
3. **界面即插即用**：自动继承 dsh web 的主题/语言（CSS 变量 + locale 服务），无需单独设计换肤。
4. **浏览器存储**：收藏/历史/缓存用 localStorage + IndexedDB，纯本地，无服务器。
