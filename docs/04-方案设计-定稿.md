> 形态已按问卷确认改为 **DSH Web 插件**（与「对话」「轨迹」同级）。本方案基于对 DSH 源码的实际调查（slots 契约、client 插件机制、参考插件 dsh-view-manager / dsh-theme-manager）与公共 API 实测。

## §1 一句话方案

做一个 **DSH Web 插件**：安装后在会话页头注册一个「诗词」标签页（与「对话」「轨迹」并排，同一机制），提供 **免 token 的诗词查询**（免费公共 API 直连 + 本地缓存限速），并把「AI 解读 / 关联典故 / 节日推荐」**透传给 dsh 自己的会话**（消耗用户已有的模型配额，无需额外 API Key）。

```
┌──────────────────── DSH Web (浏览器) ────────────────────┐
│  会话页头标签栏:  [对话] [轨迹] [诗词★本插件]             │
│                                                          │
│  ┌────────────────────────────────────────────────────┐  │
│  │ 诗词视图 (conversation.view slot 条目)               │  │
│  │  ┌ 搜索/筛选/飞花令/随机/每日一首/收藏/简繁 工具栏 ─┐ │  │
│  │  └────────────────────────────────────────────────┘ │  │
│  │  结果表(工具式高密度) → 详情侧栏                     │  │
│  │    ├ 复制/分享卡片                                  │  │
│  │    └ [AI 解读] → inputActions.setDraft+submit       │  │
│  │          └──► dsh 会话 agent 回答（用现有配额）      │  │
│  └────────────────────────────────────────────────────┘  │
│        │  fetch (CORS *)                                  │
│        ▼                                                  │
│  poetry.palemoky.com 免费公共 API（免 token，限流20/8次分）│
└───────────────────────────────────────────────────────────┘
```

## §2 可行性要点（已实测/已查证）

| 项 | 状态 | 证据 |
| --- | --- | --- |
| 注册「诗词」标签页 | ✅ 可行 | `conversation.view` 是 list slot，「对话」(chat)「轨迹」(trajectory) 均为其条目；第三方插件同机制注册（见 `dsh-client-ui-conversation/lib/types/client/contract/slots.d.ts` L78） |
| 免 token 数据源 | ✅ 可行 | 公共 API 无鉴权 + CORS `*`（实测所有端点 200） |
| 数据量 | ✅ 37.1万首 / 1.36万作者 / 11朝代 / 17体裁 | 实测 `/api/stats` |
| 限流 | ⚠️ 20次/分（普通）8次/分（搜索） | 实测 429 + `Retry-After` 头；方案内置缓存+令牌桶消化 |
| AI 解读 | ✅ 可行 | client 插件可获得 `inputActions`（`setDraft`+`submit`，见 `input/contract.d.ts` L65-76），把提示词交给当前会话 agent |
| 无后端兜底 | ✅ 可行 | 浏览器 localStorage/IndexedDB 纯本地；公共 API 为主源 |
| 安装 | ✅ 简单 | `dsh plugin --profile web add <pkg>` 一键安装，重启生效（dsh 0.1.0-rc.6 已实测 profile 含第三方插件） |
| 开源发布 | ✅ 可行 | 参考插件均为 npm/GitHub 双渠道分发（如 `dsh plugin add github:xxx/repo`） |

**技术前提（已验证存在）**：
- client 插件手写 ModuleLoader bundle，**无构建步骤**：`window.__ModuleLoader__.load({id, factory})` + `exports.apply` + `exports.inject`
- 所需服务：`slots`（注册视图）、`locale`（中英文案）、`sessions`（会话快照）、`conversation`（可选，拿 `inputActions`/`useInput`）
- 样式用 `--dsw-alias-*` CSS 变量，自动跟随 dsh 主题
- host 半部（`lib/index.js` + `cordis.patch.yml`）可为空实现（参考 dsh-view-manager）

**client.js 骨架**（核心注册逻辑，模式已验证）：

```js
window.__ModuleLoader__.load({
  id: "dsh-chinese-poetry",
  factory: (require) => {
    var React = require("react");
    var NS = "chinesePoetry";

    function apply(ctx) {
      ctx.effect(() => ctx.locale.register(NS, { zh, en }), "poetry: dicts");
      var t = ctx.locale.bind(NS);

      // ★ 注册「诗词」标签页 —— 与「对话」「轨迹」同级
      ctx.slots.inject("conversation.view", () => ctx.slots.register({
        name: "conversation.view",
        id: "poetry",               // 视图 id（持久化于会话 store）
        order: 20,                  // 排在对话(隐式)轨迹(10)之后
        locale: NS,
        label: () => t("view.poetry"),
        inject: (sessionId) => ({
          poetry: createPoetryDataLayer(),  // 数据层实例（缓存+限速）
          input: /* 会话输入动作，供 AI 解读使用 */,
        }),
      }, PoetryView));

      // ★ 会话页头工具按钮（可选）：打开独立面板 / 每日一首
      ctx.slots.inject("conversation.session.header.utilities", () =>
        ctx.slots.register({
          name: "conversation.session.header.utilities",
          id: "poetry-quick",
          order: 20,
          locale: NS,
          inject: () => ({ poetry: createPoetryDataLayer() }),
        }, PoetryQuickButton));
    }
    exports.apply = apply;
    exports.inject = ["slots", "locale"];
    return module.exports;
  },
});
```

## §4 功能设计

### 4.1 视图布局（工具式，高信息密度）

```
┌ 工具栏 ─────────────────────────────────────────────────┐
│ [搜索框 q][类型▾ 五绝/七绝/…][朝代▾][作者▾][简繁]      │
│ [飞花令: 字输入][随机一首][每日一首][收藏]              │
├ 结果表 ────────────────────────────────────────────────┤
│ 标题      作者     朝代   体裁   内容预览       操作     │
│ 静夜思    李白     唐     五言绝句 床前明月光… [详情][❤] │
│ …                                                       │
├ 详情侧栏（点行展开/右侧）─────────────────────────────┤
│ 全诗 + 作者/朝代/体裁标签 + 简繁切换                     │
│ [复制全诗][复制纯文本][分享卡片图][AI 解读][收藏]        │
└─────────────────────────────────────────────────────────┘
```

### 4.2 数据层（免 token + 抗限流，本方案核心）

```js
class PoetryDataLayer {
  // 1) 令牌桶限速：普通 15 次/分、搜索 6 次/分（留安全余量）
  // 2) 缓存：元数据(朝代/体裁/作者) 7天；搜索结果 24h；详情 24h（localStorage + IndexedDB）
  // 3) 429 处理：读 Retry-After → 指数退避(1s/2s/4s→60s)；连续3次自动降级到“仅本地缓存+离线小表”
  // 4) 队列：并发1，优先级 搜索 > 随机 > 元数据
  async search(q, filters) { ... }
  async random(filters) { ... }
  async daily() { /* 每日一首：日期为 key 的确定性随机 */ }
  async meta() { ... }
}
```

**429 免疫设计（对应你"用几次就 429"的痛点）**：
- 常规搜索+浏览路径全部命中缓存或 ≤6 次/分搜索配额 → **日常使用永远不触发 429**
- 飞花令用 `random?char=`（普通接口，非搜索接口）→ 不占搜索配额
- 离线小表：内置常用 300 首（李白/杜甫/苏轼/李清照高频篇目）+ 节日诗词映射，断网/429 时兜底展示

### 4.3 AI 增强（走 dsh 会话，接受 token）

| 功能 | 实现 | token 消耗 |
| --- | --- | --- |
| AI 解读 | 详情页 [AI 解读] → 构造提示词「请解读这首古诗《静夜思》（李白·唐）：…」→ `inputActions.setDraft(p)` + `inputActions.submit()`（默认不自动提交，见待确认项） | 用户自己的 dsh 模型配额 |
| 关联典故 | 同一入口，提示词追加「并说明诗中的典故/用典出处」 | 同上 |
| 节日/节气推荐 | 内置节气/节日→诗词映射表（本地，免 token）+ [AI 生成应景诗] 按钮走会话 | 本地部分 0 token |

> 为什么用会话透传而不是直调模型：dsh 的模型调用/配额/密钥管理在 host 侧，client 插件没有也不应持有密钥；透传给会话是最简单、最安全、且天然复用的方式。

### 4.4 每日推送

- 打开 dsh web 时检查 localStorage 中「今日已推送」标记，未推则：
  - 「诗词」标签页顶部展示今日一首（确定性随机：按日期 seed）
  - 浏览器 Notification（可选，需用户授权）
- 节日当天自动替换为节日专题（本地映射表）

### 4.5 收藏 / 历史

- localStorage（小） + IndexedDB（大）纯本地存储
- 导出 JSON；不涉及任何服务器
